## 未完成与已知限制

| 项目 | 当前情况 |
| --- | --- |
| 完整关卡流程 | 有通关判定、提示、入口流程下的返回和手动下一关，尚无评分、全通关汇总及进度存档 |
| 玩法关卡返回 | 入口进入后可在通关时返回；关卡中途返回菜单尚未实现，直接运行关卡不显示流程按钮 |
| 自制关卡列表 | 已有收纳、展开、滚动和按钮反馈，未连接实际关卡加载 |
| 场地变化运行 | 方案编辑、预览和检查可用；祭坛触发、生成、坍塌与撤离未接入 |
| 操作失败反馈 | LastFeedback 会保存失败原因，但尚无统一可见提示，玩家可能只看到动作未发生 |
| 大棋盘撤销成本 | 完整快照会重复复制静态地形，512 步在大棋盘上的内存与延迟需测量 |
| 谜题与死局 | 没有自动解法、死局检测或提示；数据校验不保证关卡可通关 |
| 资源中的预留外观 | 大体型妖怪执行近战接触攻击，没有 Boss 阶段；祭坛为阻挡物，药瓶等饰物仅用于角色识别 |
| 入口与关卡覆盖 | Levels 中存在场景不等于庭院已经配置入口，也不等于全部场景已完成人工解法验收 |

## 版本与交付边界

工程使用 Unity 2022.3.51f1，按当前指定版本导入与验收。本轮不更换编辑器，也不提供 WebGL 模板或打包产物；不能把“可在编辑器运行”直接当作“已通过公开发行安全与平台适配检查”。

上传前核对第三方组件和资源许可证，保留所需的来源与使用说明；编辑器形式、公开范围和其他提交限制以实际提交要求为准。

## 上传前人工验收

- [ ] 在干净检出目录使用指定 Unity 版本完成依赖恢复、导入和编译，不依赖本机 Library 或 Archive。
- [ ] 从 StartMenu 进入庭院，逐个确认要展示的入口编号、目标场景和按住 V 预览均有效。
- [ ] 主菜单退出、庭院返回与列表滚动正常，预览淡入淡出后没有残留输入锁或重复 UI。
- [ ] 逐关完成一遍实际解法，确认目标点数量、初始敌人接触和通关条件符合设计。
- [ ] 从庭院进入后通关可返回，下一关遵循入口编号顺序，最后一关不显示下一关；撤销和重开收起按钮，直接运行关卡不显示按钮，通关文字悬停不变色。
- [ ] 保存关卡只更新目录与预览，不改变构建名单、勾选和顺序；未纳入发布的草稿不被自动加入，缺失的入口目标会在构建前被明确报告。
- [ ] 力士三连推、盗贼自动拉、法师换位与盾兵普通移动均正常；受阻操作不改占位。
- [ ] 普通门保持/切换、全板关联、封印门清空敌方、木箱压碎、水晶不可破坏、关门致死与连锁释放符合规则。
- [ ] 敌人互杀、火龙朝向和遮挡正确，死亡后可 Ctrl+Z 或 R，目标点变黑；撤销能完整恢复。
- [ ] 切人闪白 0.2 秒、木箱闪白 0.3 秒、脚下光圈和黄色通关提示在实际画面中清楚可见。
- [ ] 新建关卡默认无角色、目标与棋盘花草；地形分组、独立障碍、矩形保留实体及五类物件分组正常。
- [ ] 压力板候选仅限当前关卡，Scene 坐标可见；跨关卡或失效引用能被拒绝。
- [ ] 环境/花草刷新、位置双向同步与 Unity Undo 不破坏已有布局；只读工程检查不产生保存或配置改动。
- [ ] 场地变化预览退出、保存、进 Play 和重载后能恢复初始显示，不把预览保存进正式场景。
- [ ] Unity 文档窗口中的导航、源码编辑与资源链接可用，仓库网页上的相对文档链接也可用。
- [ ] Assets 的 .meta、Packages、ProjectSettings、许可证和 README 已包含；缓存、备份与私有题面未误上传。
