# Gameplay

本项目在玩法设计上借鉴并学习了《沉星之序》中多角色协作搬运与推箱子解谜的思路。

多角色协作的格子推箱子。通过移动、推拉、换位与机关配合，让我方角色同时占据所有目标点。

## 操作

先点击 Game 视图，让游戏获得键盘焦点。

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 移动 | W / A / S / D | 棋盘上、左、下、右；可按住连续移动，不支持斜走 |
| 切换角色 | Q | 按角色层级顺序轮换，新角色闪白 0.2 秒，脚下光圈标明当前角色 |
| 撤销一步 | Ctrl+Z | 恢复整步的位置、存亡及机关状态；不支持重做 |
| 备用撤销 | Backspace | 仅在没有我方死亡时可用 |
| 重开 | R | 立即恢复本次进入关卡时的初始状态并清空撤销记录；死亡、通关或行动演出途中均可用 |
| 缩放 | 鼠标滚轮 | 固定透视镜头推近或拉远，不拖动、不旋转 |
| 进入关卡 | E | 仅在选关庭院站上有效入口时可用 |
| 预览关卡 | 按住 V | 仅在入口上可用；松开后收起 |
| 庭院返回 | Esc | 先收起展开的自制列表，否则返回主菜单；不是玩法关卡的通用返回键 |

移动和机关演出期间暂不接受下一次移动或切人，但可按 R 中断并重开。预览淡入、停留与淡出期间锁定角色操作和选关菜单。

## 我方角色

能力由移动方向自动触发，没有单独的攻击或技能按钮。

| 角色 | 外观 | 能力与限制 |
| --- | --- | --- |
| 力士 | 红色，粗壮双臂 | 向前移动时可推动连续最多三个可移动物体，木箱、水晶、我方角色与敌人可以混合连推；整条路径和终点都合法才一起移动 |
| 盗贼 | 绿色，腰侧钩子 | 移动时自动拉动身后相邻的一个木箱、水晶或我方角色，到自己原来的格子；不能推动 |
| 法师 | 蓝色，尖帽与法杖 | 沿输入方向寻找直线上最近的木箱、水晶或其他我方角色，找到就换位；敌人不能换位，阻挡物会挡住查找；没有合法目标时尝试正常走一格 |
| 盾兵 | 黄色，大盾 | 只有普通移动，不推动、不拉动，没有格挡免伤或其他特殊能力 |

角色正面是两条横线眼睛，后脑是黑色头发，可以据此判断面向。光圈保持在脚下，重叠地面机关时优先显示，但不覆盖人物模型，不抬高位置。

## 地面与障碍

- 草地、土地和浅灰地面只是配色不同，基础通行规则相同。
- 石块、灌木是不可搬运的阻挡物，挡路、挡火，也阻挡法师的换位查找。
- 高地需要相接的通路；不能直接从侧面爬上或跳下。坡道只有两端高度匹配时才可通过。
- 深渊没有支撑，不能普通行走、推动或拉动进入。法师的换位不经过中间格，可以跨过深渊，但双方落点都必须合法。
- 当前没有坠落伤害、高地伤害加成或掩体规则。

## 可移动物

| 物体 | 用途 | 关门时 |
| --- | --- | --- |
| 木箱 | 推、拉、换位、压板、挡路和挡火 | 门格上的木箱会被压碎，闪白 0.3 秒后消失 |
| 水晶 | 搬运、压板与阻挡规则和木箱相同 | 不可破坏；占住门格时会阻止门关闭 |

箱子和水晶不能替代我方角色激活目标点。敌人不会主动攻击箱子；火焰遇到它们会被阻挡，而不是烧毁它们。

## 压力板与门

角色、敌人、木箱或水晶都能压下压力板。

普通门检查所有关联压力板。保持式门在全部压下时打开，信号解除时关闭；配置为切换式的门，在每次“全部压下”重新成立时切换一次开关，不会因为持续站在板上反复切换。

门关闭会压死门格上的我方或敌方人物。我方沿用受敌人攻击后的倒地与死亡锁定，敌方消失；木箱被压碎，水晶保留。压死或压碎也可能释放其他压力板，连锁变化在同一步内结算。

封印石门不依赖压力板。场上还有存活敌人时关闭；清空敌人后封印亮绿，等待 1 秒再下降打开。火龙石像也计入敌人。

## 敌人与威胁

普通敌人不主动移动，可以被力士推动。它们攻击上下左右相邻的我方角色或其他敌人，命中即死；相邻的普通敌人会互相攻击、同时死亡。持枪哨兵和大体型妖怪目前没有额外射程或 Boss 阶段能力，仍遵循普通接触攻击规则。

火龙石像保持摆放时的朝向，正前方直线上有我方或敌方人物就立即喷火：

- 射线一直延伸到棋盘边界；石块、灌木、箱子、水晶、其他阻挡物及关闭的门挡火。
- 人物不挡火，同一条线上可以同时命中多个目标；空格和深渊不截断火焰。
- 石像不攻击侧面和背面的相邻格，也不进行普通近身攻击。
- 把普通守卫推到石像正前方相邻格，两者可以互相攻击、同时死亡；从侧面接近的守卫可能单方面击倒石像。

成功移动或换位后才推进攻击结算；开局的初始接触也会结算。切人、无效移动和撤销不会额外触发敌人攻击。

## 通关、死亡与撤销

所有绿色目标点同时由存活我方角色占据时通关，不要求所有我方角色都站点。箱子、水晶与敌人不激活目标点。

通关后显示固定黄色加粗的“关卡完成！”，鼠标悬停不变色，停止移动与切人；仍可撤销最后一步或按 R 重开。

从选关庭院入口进入关卡时，通关演出完成后左下角显示“返回选关”，右下角显示“下一关”。下一关按本次庭院已配置的 `1-1、1-2…` 入口编号顺序进入；没有后续关卡时不显示下一关。不会自动跳转。直接在编辑器打开玩法关卡运行时不显示这两个按钮。撤销通关或重开后按钮收起。

任一我方角色死亡即失败，所有目标点变黑并失效，移动和切人锁定，可用 **Ctrl+Z 撤销或 R 重开**。我方倒地，死亡敌人和破坏木箱消失。撤销一起恢复该步的占位、存亡、压力板与门；最多保留最近 512 步。没有可用的撤销记录时不能撤销。

关卡没有目标点时不会自动通关。撤销和重开只改变本次游戏，不会修改作者保存的关卡文件。
